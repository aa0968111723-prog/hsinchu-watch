# 完整收錄資料頁

`/archive.html` 把已保存的八類資料整合為18,402筆紀錄（本次快照）。新聞9,164、政策1,879、民調83、匿名留言觀點23、公開來源索引7,205、本人／機關發言21、議題立場摘錄23、治理案卷4。這是紀錄數，包含同篇原文跨人物、跨類型的不同整理；不是不重複新聞或事件數。

資料頁保留所有來源檔中的對應紀錄，包括不計入分析統計的封存參考。每頁25／50／100筆、可翻至最後，CSV／JSON匯出的是全部符合篩選的紀錄。來源、人物與身分、類型、平台、資料日期、資料狀態和文字篩選可同時使用，網址保留篩選條件。

人物清單區分目前兩選區的六位正式候選人與其他人物／歷史資料；不把評論人物當候選人。治理案卷沒有證據連結特定人物時不任意歸功。原始紀錄可展開，摘要、自動標籤與既有整理日期都不等於本輪重新查證。

日期不統一假定為發布時間：新聞和政策用來源發布日，留言用留言時間，治理用事件日期，來源索引用原有日期。年月精度或未知日期不補成月初；指定完整日期範圍時暫不列入，清除日期篩選仍可查到。晚於統計快照的原有時間標示待核對。

匿名留言不顯示帳號，紀錄和匯出都通過既有sanitizeItem。未核對民調只保留可顯示的日期及來源欄位，不輸出支持度；標題及備註百分比改以未核對標示。民調原始檔入口改連至民調頁。封關期間不載入民調檔，其他類型的民調相關內容也暫不列出；匯出、完整欄位和檔案入口都適用同樣限制。分頁、匯出、頁面重回前景與期間邊界會重新確認限制。

資料檔目錄保留manifest中的19份快照和兩份觀察資料入口；分片、latest、統計、名單、詞頻及照片來源是已保存資料的另一種形式，不再次計入18,402。封關期間暫停本頁的原始選舉資料下載入口，不宣稱改變既有公開伺服器網址的存取權限。

載入時核對manifest內檔案的位元組長度與SHA-256。失敗顯示缺少的檔案與原因，保留其他可查內容，暫停匯出並提供重試；不把部分載入寫成完整收錄。

本站未保存的資訊不在本頁，亦未備份新聞全文。既有資料與匿名摘錄不因本次整合而修改；原文以來源網站為準。
