## 3. 四個案卷的位置

座標順序是 [經度, 緯度]。精度的意思：`site` 是機關公布的基地點位；`street` 是原文寫到的路段
或路口；`unknown` 是沒有可核對的座標，geometry 為 null。

### 3.1 中山區培英公共住宅（`taipei-peiying-housing`）— site

- 位置原文：「選定位於中山區永安里並鄰近明水公園的『培英公共住宅』……本基地面積2,898.24平方公尺」（[工程頁](https://heo.gov.taipei/cp.aspx?n=DEDCC5E8E17CD3FB)）。
- 座標：121.548438, 25.079967。來自主辦機關在同一工程頁嵌入的官方地圖（水利工程處「重要主題專案」），標記名稱「臺北市中山區培英基地公共住宅新建工程」，標記說明連回同一工程頁。
- 交叉核對：
  - 落在臺北市中山區（對 `districts.geojson` 做點在多邊形內判斷）。
  - 國土測繪中心點位查詢回傳「臺北市中山區永安里（北安段三小段）」，與原文的永安里一致。
  - OpenStreetMap 上名為「培英社會住宅(施工中)」的施工範圍約 2,480 平方公尺，比原文的基地面積少 14.4%；**標記點在這個範圍的邊緣外 5.2 公尺，不在範圍內**。兩者相鄰但不重合，照實記錄。
  - 距 OpenStreetMap 上的明水公園 38 公尺，與原文「鄰近明水公園」相符。
- 限制：座標是機關地圖上的一個標記點，不是建物輪廓的實測角點。

### 3.2 思源路跨越新北大道人行天橋（`new-taipei-siyuan-footbridge`）— street

- 位置原文：「本案新建天橋位於新莊區新北大道及思源路口，跨越新北大道銜接捷運環狀線Y20新北產業園區站空橋電梯，橋梁長度達72公尺(58公尺 14公尺)」（[新北市政府施政成果網](https://wedid.ntpc.gov.tw/Governance/Detail/kdqlJDJpPQje)，由工務局在建工程專區連入）。
- 座標：121.459841, 25.060478。取 OpenStreetMap 上思源路與新北大道三段中心線相交的五個路口號誌節點的平均位置（節點最遠離平均點 15.8 公尺）。
- 交叉核對：落在新北市新莊區；距環狀線 Y20 車站節點 88 公尺。
- 限制：這是路口位置，不是天橋落墩或梯口的實測位置。OpenStreetMap 還沒有畫出這座施工中的天橋。

### 3.3 新埔褒忠路道路拓寬（`hsinchu-county-baozhong-road`）— street

- 位置原文：「縣道117線18K+480-19K+840(褒忠路)道路拓寬工程……工程改善範圍自義民路路口起，向南跨越鳳山溪至縣道118線(文山路)交會處，全長1360公尺（含280公尺的褒忠大橋）」（[新竹縣政府新聞稿](https://www.hsinchu.gov.tw/News_Content.aspx?n=153&sms=8603&s=358194)）。

## 4. 階段對照

`public/data/geo/project-stages.json` 把治理案卷的官方紀錄逐項對到規劃、核定、施工、完工、驗收、
啟用、實際成效七格。每一格只寫來源有寫的事：

| 狀態 | 意思 |
| --- | --- |
| `documented` | 來源記載已發生，並有日期（附日期精度） |
| `stated_undated` | 來源提到，但沒有寫日期 |
| `in_preparation` | 來源寫正在準備，結果未收錄 |
| `not_recorded` | 本站尚未收錄，不代表沒有發生 |

整理時在官方頁面看到、但治理案卷目前沒有的資料，放在同一個檔案的附屬欄位，沒有改動治理案卷：

- 培英公宅工程頁寫「工程金額：9億3,824萬元」「決標日期：108年10月1日」。原文用語是「工程金額」，沒有註明是核定還是決標，所以只列為原文數字，核定／決標／實支三欄維持 null。
- 褒忠路新聞稿的核定經費分攤：中央款 7億7042萬元（79%）、地方配合款 2億479萬元（21%），兩者相加等於核定經費 9億7521萬元。
- 思源路天橋的開工月份（114年12月）來自施政成果網；治理來源目錄尚未收錄這一頁。

褒忠路新聞稿提到縣長、鎮長與立法委員出席開工動土典禮。對照檔只記「出席典禮」這個來源寫明的
關係，並註明不代表個人對核定、經費或工程成果的責任歸屬。

## 5. 插畫與示意

立體示意視角的底座、腳墊、尺規、銘牌與指北盤是程式產生的原創插畫，用
[anatomy](../../src/atlas/kit/LICENSE-anatomy.txt) 繪圖工具組（MIT 授權）。沒有使用外部圖片。
共用參考圖 `reference/11351.jpg` 只取「明亮的插畫地圖」這個方向，沒有複製其中任何內容。

- 厚度只為了立體感，不代表高程、預算或任何評分。
- 尺規的刻度間距是真實地面距離。
- 地區的底色只用來分辨縣市。
- 圖釘上的字是七個階段裡最新有紀錄的一格，不是完成度。
